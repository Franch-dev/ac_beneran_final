📐 Response Standard

All JSON endpoints use a standardized response envelope via App\Support\ApiResponse.

Success — 200 OK ✓ 200 
{
  "success": true,
  "order": { "id": 1, "order_number": "SO-2024-0001" },
  "message": "Optional success message"
}
Error — 4xx ⚠ 4xx 
{
  "success": false,
  "message": "Error description",
  "errors": {
    "field": ["Validation message"]
  }
}
Snapshot — AJAX partial page refresh ✓ 200 
{
  "html": "<div>...rendered HTML...</div>"
}

🔄 Real-time Sync

Server-Sent Events (SSE) stream for real-time cross-tab/browser updates.

GET /sync/stream
auth

Accepts Last-Event-ID header or last_event_id query parameter.

Event format:
id: {event_id}
event: sync
data: {"id":1,"type":"created","resource":"service_order","resource_id":1,...}

retry: 2000
: heartbeat

Events: service_order.created, service_order.approved, service_order.deleted, workflow.assigned, anggota.created, etc.
